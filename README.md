# uBlockOrigin AI-Assistant-Blocklist

Blocklist des sites d'**assistants conversationnels IA** (ChatGPT, Gemini, Claude, Le Chat, Perplexity, Copilot, Grok, Duck.ai, DeepSeek, Meta AI…).

## Installation (uBlock Origin)

1. Ouvrez le tableau de bord uBlock Origin → onglet **Listes de filtres** → **Importer**.
2. Collez l'URL de la liste souhaitée :
   ```
   https://raw.githubusercontent.com/luc4rto/uBlockOrigin-AI-Assistant-Blocklist/main/list.txt
   ```
3. **Appliquez les modifications**. uBO rafraîchit la liste automatiquement une fois par jour.

## Installation (uBlacklist)

1. Options de l'extension → **Abonnements** → **Ajouter un abonnement**.
2. URL :
   ```
   https://raw.githubusercontent.com/luc4rto/uBlockOrigin-AI-Assistant-Blocklist/main/list_uBlacklist.txt
   ```
3. Réglez l'intervalle de mise à jour sur 1 heure, et activez vos moteurs de recherche dans « Autres moteurs de recherche ».
